
HTML - It has collections of tags with limited property and values.

CSS - Cascading Style Sheet 
      It has collections of only property and values. 
      it change look and feel of html. 

      Responsive webpage = html(tags) + CSS(property & values)

Type of CSS ?
    1. inline 
    2. internal 
    3. external css 
    4. import css 

1. inline CSS 
    syntax 
        <tagname style="property:value; property2:value; property3:value;"> </tagname>

    example 
        <p style="height:300px; width:400px; background:red;"></p>

2. internal css 
     syntax
        selector{
            property1:value;
            property2:value;
            property3:value;
        }

    example 
        p{
            padding:70px 30px 70px;
            background:skyblue;
            float:left;
            margin:40px; 
            width:350px;
        }
    All html tags are called selector in css. 
      
      CSS Has 6 type of selector to combine html with css. 
        -----------------------------
          1. tag selector 
            example 
                 div{
                        margin:2%;
                        width:46%;
                        float:left;
                        font-size:22px;
                        color:purple;
                    }
        ------------------------------
          2. group selector 
            example 
              h1, p, div, h3{
                font-style:italic; 
            }
        ------------------------------
          3. id selector 
             example 
                #block1{
                    background:skyblue;
                    height:100px;
                }
        Note - one id we should use only 1 time in 1 page else js will face problem 
        ------------------------------
          4. class selector
            example
                .service{
                    margin:2%;
                    width:21%;
                    height:250px;
                    background:purple;
                    float:left;
                }
            Note - one class can be use 1 time or multiple time in a page 
        --------------------------------
          5. parent child selector 
                example
                    #service p{
                        width:21%;
                        margin:2%;
                        height:300px;
                        background:red;
                        float:left;
                    }
        ---------------------------------
          6. attribute selector 
            example 
                input[type="text"]{
                        width:250px;
                        color:red;
                        padding:4px;
                 }
        -------------------------------

        h1{} - tag selector 
        h1, h2{} - group selector 
        div p{} - parent child selector
        #abc{} - id selector 
        .xyz{} - class selector
        input[type="text"]{} - attribute selector

--------property list--------
   height - 3 type 
    height:auto;  it is fully based on contents 
    min-height:100px; it take min height 100px even no data. if data is more it extends automatically
    height:200px; it is fully fixed for 200px height, if data is more it will overflow 
-----------------------------
   width - 4 type 
      width:px 
      width:% 
      min-width:px 
      max-width:px 
-----------------------------
   background - 9 type 
    background:red
    background-color:red
    background-color:rgb(100, 200, 220); - 0 to 255 
    background-color:rgba(100, 200, 220, 0.5); -  0.1 to o.9
    background-image:url("1.jpg")
    background-image:linear-gradient(red, green)
    background-image:linear-gradient(to left, red, green)
    background-image:linear-gradient(to right, green)
    background-image:linear-gradient(top top, green)
------------------------------

   float - it convert from block level tag to inline tag 
           float:left;  it print from left to right 
           float:right; it print from right to left 

    margin - it apply space outside of tag 
        margin:auto; it print in center of area 
        margin:40px; it apply 40px gap all side 
        margin-top:
        margin-bottom:
        margin-left:
        margin-right:
        margin:top right bottom left;

    padding - it apply space insite tag 
        padding:40px; all side gap 
        padding-top:
        padding-left:
        padding-right:
        bottom-bottom:
        padding:top right bottom left;
    
    border in css 
        type of border 

        ->solid 
        ->dotted
        ->dashed 
        ->double 
        ->inset 
        ->outset 
        ->ridge 
        ->groove 
    border:10px solid red;

    display - 
        display:inline - it convert from block level tag to inline but height & width do not work 
        display:inline-block - it convert from block level to inline even height and with will work 
        display:none - it hide the tag 
        display:block - it convert from inline tag to block level tag 
                        it print hidden tag in new line 
        display:grid 
        display:flex
